# StimeMC 홈페이지 콘텐츠 개편

StimeMC를 단일 마인크래프트 서버가 아닌 여러 독립 서버를 운영하는 Minecraft Server Group으로 전환한다.

## 주요 변경사항

- 메인 홈페이지는 개별 서버가 아닌 StimeMC 그룹을 소개한다.
- 기존 서버는 Stime Legacy로 분류한다.
- 신규 서버는 독립적인 브랜드와 운영 체계를 가진 산하 서버로 소개한다.
- 개별 서버의 소개, 규칙, 접속 방법 등은 "/서버명" 경로로 분리한다.

## 메인 홈페이지 구성

- Hero: StimeMC 서버 그룹 소개
- Servers: 산하 서버 목록 및 개별 페이지 연결
- Technology: 자체 개발 시스템 및 기술
- About: StimeMC의 역사와 운영 방향
- News: 그룹 및 산하 서버의 주요 소식

기존 도메인, 인증 시스템 및 주요 기능은 유지한다. 확정되지 않은 신규 서버 정보는 임의로 작성하지 않는다.
