# Stime Networks Website — Design Overhaul

## 1. 프로젝트 목표

기존 Stime Networks 홈페이지의 UI/UX를 전면 리디자인한다.

Inception Labs(https://www.inceptionlabs.ai/)의 독창적인 ASCII 그래픽, 인터랙티브 애니메이션, 공간 활용 방식을 참고하고 첨부된 디자인 레퍼런스 이미지를 기반으로 구현한다.

일반적인 마인크래프트 서버 홈페이지가 아닌, 독립적인 게임 개발 스튜디오 또는 현대적인 기술 기업의 홈페이지와 같은 완성도를 목표로 한다.

기존 홈페이지의 기능, 콘텐츠, 페이지, 서버 연동 시스템은 유지한다. 디자인을 변경한다는 이유로 기존 기능을 삭제하거나 임의의 정보로 대체하지 않는다.

## 2. 디자인 레퍼런스 활용

- 첨부 이미지를 전체적인 시각적 방향의 주요 레퍼런스로 사용한다.
- Inception Labs 홈페이지를 직접 분석하여 ASCII 렌더링, 애니메이션, 여백, 화면 전환 방식 등을 참고한다.
- 이미지와 사이트를 그대로 복제하지 않고 Stime만의 디자인으로 재해석한다.
- 첨부 이미지의 텍스트, 메뉴, 로고, 서버 정보 등은 예시이므로 실제 프로젝트의 정보를 우선한다.

## 3. 핵심 디자인 방향

Dynamic ASCII + Modern Minimalism

- 넓고 여유로운 여백
- 정돈된 레이아웃과 명확한 시각적 계층
- 몰입감 있는 실시간 ASCII 배경
- 부드럽고 자연스러운 인터랙션
- 절제된 색상과 시각 효과
- 세련된 현대적 UI 컴포넌트
- 높은 가독성과 접근성

ASCII 그래픽은 핵심적인 디자인 요소로 사용하되, 전체 홈페이지를 터미널이나 콘솔처럼 디자인하지 않는다.

지나치게 각진 버튼, 사각형 카드, 과도한 테두리, 터미널 스타일 텍스트는 지양한다.

## 4. 실시간 ASCII 배경 시스템

이번 리디자인에서 가장 중요한 요소이다.

### 기본 요구사항

- 메인 화면의 배경 전체에 ASCII 그래픽을 적용한다.
- 정적인 이미지나 반복 재생되는 영상이 아닌 실시간 렌더링 방식으로 구현한다.
- ASCII 그래픽의 형태가 시간이 흐름에 따라 지속적으로 변화해야 한다.
- 각 형태는 문자 단위에서 자연스럽게 생성, 이동, 분해 및 재구성된다.
- 갑작스러운 장면 전환이나 단순한 이미지 페이드 효과로 대체하지 않는다.

### 그래픽 형태 예시

- 거대한 산맥과 지형
- 물결과 유체 형태
- 구체 및 행성
- 마인크래프트 스타일의 블록과 구조물
- 추상적인 3D 오브젝트
- Stime 로고
- 절차적으로 생성되는 풍경

그래픽은 반드시 마인크래프트 오브젝트로만 제한하지 않는다. 추상적이고 예술적인 형태도 적극적으로 활용한다.

### 애니메이션

- 서로 다른 형태 사이의 부드러운 모핑(Morphing)
- 지속적인 지형 및 표면 변형
- ASCII 문자의 밀도 및 밝기 변화
- 느리고 자연스러운 3D 회전
- 마우스 움직임에 따른 미세한 패럴랙스 효과
- 스크롤 위치에 따른 그래픽 형태 변화
- 오브젝트가 문자 입자로 분해된 후 재구성되는 효과

애니메이션은 과도하게 빠르거나 산만하지 않아야 한다. 페이지를 장시간 보고 있어도 부담스럽지 않은 수준으로 구현한다.

단순한 무작위 문자 나열이 아니라 실제 입체감, 명암, 깊이, 표면의 형태를 표현할 수 있어야 한다.

## 5. 메인 화면(Hero Section)

첫 화면은 뷰포트 전체 높이를 활용하는 몰입형 레이아웃으로 구성한다.

- 상단: 심플하고 현대적인 내비게이션
- 중앙 또는 좌측: 브랜드명, 메인 슬로건, 간결한 소개 문구
- 주요 버튼: 서버 접속 및 콘텐츠 탐색
- 배경: 지속적으로 변화하는 대형 ASCII 그래픽
- 하단: 작고 간결한 스크롤 유도 아이콘

첫 화면에 너무 많은 정보를 배치하지 않는다.

하단 고정 정보 바, 접속자 통계 바, 불필요한 카드 및 복잡한 장식 요소를 제거한다. 관련 정보는 스크롤 이후의 콘텐츠 영역에 자연스럽게 배치한다.

텍스트와 ASCII 그래픽이 공존하되, 배경 때문에 텍스트의 가독성이 저하되지 않도록 한다.

## 6. 스크롤 및 전체 페이지 구성

홈페이지는 첫 화면에서 끝나는 단일 랜딩 화면이 아니다.

사용자가 아래로 스크롤하면 기존 홈페이지의 주요 콘텐츠가 순차적으로 나타나야 한다.

### 콘텐츠 구성 예시

1. 몰입형 Hero Section
2. Stime Networks 소개
3. 게임 모드 및 서버 소개
4. 주요 특징과 자체 개발 시스템
5. 시즌 및 업데이트 소개
6. 서버 접속 정보
7. 커뮤니티 및 관련 링크
8. Footer

실제 구성과 순서는 기존 홈페이지의 구조 및 콘텐츠를 분석하여 결정한다.

각 섹션에 충분한 여백을 부여하고, 모든 콘텐츠를 사각형 카드 안에 넣는 방식은 피한다.

ASCII 그래픽은 메인 화면뿐 아니라 주요 섹션의 배경, 전환 및 시각적 포인트에도 활용할 수 있다. 단, 본문 영역에서는 가독성을 우선하며 필요한 경우 그래픽의 밀도와 밝기를 낮춘다.

## 7. UI 컴포넌트

ASCII 그래픽과 일반 UI 디자인을 명확하게 구분한다.

일반 UI는 현대적인 웹 디자인을 기반으로 한다.

- 적당한 라운딩을 적용한 버튼
- 간결한 내비게이션
- 현대적인 산세리프 폰트
- 제한적으로 활용하는 모노스페이스 폰트
- 자연스러운 Hover 효과
- 부드러운 페이지 전환
- 절제된 투명도와 블러 효과
- 필요한 경우에만 사용하는 얇은 구분선

다음 디자인은 지양한다.

- 과도한 네온 및 발광 효과
- 불필요한 그라데이션
- 지나치게 많은 카드
- 과도한 테두리 및 그리드
- 전체적인 터미널 UI
- 전형적인 마인크래프트 픽셀 아트 UI
- 일반적인 AI 생성 웹사이트 템플릿 스타일
- 불필요하게 복잡한 화면 구성

색상은 Inception Labs와 동일할 필요가 없다. 기존 Stime 브랜드와 조화를 이루도록 구성한다.

## 8. 기술적 구현

기존 프로젝트의 기술 스택과 아키텍처를 우선적으로 존중한다.

필요한 경우 다음 기술을 검토한다.

- Three.js
- WebGL / WebGL2
- GLSL Shader
- Canvas API
- GSAP
- Motion
- GPU 기반 ASCII 렌더링
- Procedural Geometry
- Noise 기반 지형 생성
- GPU 또는 CPU 기반 Morphing

ASCII 렌더링 시스템은 재사용 가능한 독립 컴포넌트 또는 모듈로 설계한다.

문자 종류, 밀도, 크기, 밝기, 형태, 애니메이션 속도 등을 쉽게 수정할 수 있도록 구현한다.

단순히 기존 라이브러리의 기본 ASCII 효과를 적용하는 수준에 그치지 않고, 프로젝트의 디자인에 맞게 커스터마이징한다.

불필요한 프레임워크 변경이나 의존성 추가는 피한다.

## 9. 성능 및 최적화

시각적 완성도와 실제 사용성을 모두 확보한다.

- 데스크톱에서 60FPS 수준의 부드러운 애니메이션을 목표로 한다.
- 기기 성능에 따른 렌더링 품질 및 해상도 자동 조절
- 모바일 및 태블릿 반응형 대응
- 화면 밖의 애니메이션 렌더링 최소화
- 비활성 탭에서 불필요한 렌더링 중단
- 페이지 로딩을 방해하지 않는 비동기 초기화
- 과도한 DOM 노드 생성 방지
- GPU 및 메모리 사용량 최적화
- WebGL 미지원 환경을 위한 대체 그래픽 제공
- prefers-reduced-motion 지원
- 애니메이션 비활성화 환경에서도 정상적인 홈페이지 사용 보장

ASCII 배경은 페이지의 핵심 기능과 독립적으로 동작해야 한다.

## 10. 작업 방식

1. 기존 홈페이지의 구조, 기능, 콘텐츠, 디자인 시스템을 분석한다.
2. Inception Labs와 첨부 이미지의 디자인 특징을 분석한다.
3. 기존 브랜드를 기반으로 새로운 디자인 시스템을 정의한다.
4. 실시간 ASCII 렌더링 및 모핑 시스템을 구현한다.
5. 새로운 Hero Section을 구현한다.
6. 나머지 페이지와 콘텐츠 영역을 일관된 디자인으로 리뉴얼한다.
7. 모바일 대응, 인터랙션 및 성능 최적화를 진행한다.
8. 기존 기능의 정상 동작 여부를 검증한다.
9. 최종 디자인과 구현 결과를 자체 검토하고 부족한 부분을 개선한다.

## 11. 완료 기준

- 첨부 레퍼런스와 유사한 수준의 몰입감과 여백을 확보할 것.
- ASCII 배경의 형태가 실시간으로 자연스럽게 변화할 것.
- 단순한 정적 이미지나 영상으로 핵심 효과를 대체하지 않을 것.
- 스크롤을 통해 전체 홈페이지 콘텐츠를 확인할 수 있을 것.
- 일반 UI는 현대적이고 세련된 디자인을 유지할 것.
- 기존 기능 및 실제 서버 정보가 유지될 것.
- 모바일에서도 디자인과 기능이 정상적으로 작동할 것.
- 전체 페이지가 하나의 일관된 디자인 시스템을 공유할 것.

최종 결과물은 단순한 디자인 시안이나 프로토타입이 아니라 실제 배포 가능한 완성도 높은 홈페이지여야 한다.

가장 중요한 것은 Inception Labs의 색상이나 레이아웃을 복제하는 것이 아니라, 살아 움직이는 ASCII 그래픽과 현대적이고 여유로운 UI가 자연스럽게 결합된 Stime만의 독창적인 웹사이트를 만드는 것이다.
