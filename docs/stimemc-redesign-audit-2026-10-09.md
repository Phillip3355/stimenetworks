# StimeMC 리디자인 사전 조사

조사일: 2026-10-09 (Asia/Seoul). 이 문서는 현재 코드와 공개 사이트에서 확인한 사실을 기록한다. 리디자인 구현은 아직 시작하지 않았다.

## 요청에서 확정된 방향

- StimeMC는 여러 Minecraft 서버를 운영하는 상위 브랜드다.
- 현재 소개 대상은 전쟁 서버 `THE GREAT WAR`와 향후 별도로 추가할 `SURVIVAL`뿐이다.
- Survival은 Vanilla / Vanilla+ 중심의 계획이며 출시 버전, 날짜, 접속 주소는 확정하지 않는다.
- 기존 역사, 실제 이미지, 공개 URL, 규칙, 복구 정책, 뉴스, 문의 기능을 보존한다.
- 모바일, 태블릿, 데스크톱의 구성과 모션을 함께 설계한다.
- 새로운 서버, 게임 시스템, 운영 정책, 가짜 실시간 데이터는 추가하지 않는다.

## 확인된 콘텐츠 문제와 불확실성

1. 홈은 기술 설명을 먼저 보여주고 `하나의 월드 · 두 개의 에디션`, 서버사이드 모드, 평화로운 플레이를 주요 차별점으로 사용한다.
2. 기술 페이지 제목은 `한 번의 접속, 하나의 월드`다. Footer와 공통 metadata도 단일 모드 서버를 설명한다.
3. 공개 코드에는 The Great War의 상세 게임 시스템, 서버별 상태 API, 플레이어 수 API, 공개 접속 주소·포트가 없다.
4. Java 1.21.1은 현재 접속 안내에서 확인되지만 새 전쟁 서버의 버전으로 확정하는 근거는 없다.
5. 기존 규칙은 살인, 테러, 건축물 파괴 금지를 포함한다. 전쟁 서버의 예외·허용 범위는 확인되지 않았다. 원문을 보존하며 적용 범위가 미확인인 규칙을 모든 서버의 공통 규칙으로 단정하지 않는다.
6. 기존 복구 정책에 전쟁 서버나 Survival 예외가 정의되어 있지 않다. 새 예외를 만들지 않는다.
7. 전쟁 서버는 요청문에서 운영 준비 중으로 설명되는 동시에 현재 플레이 가능한 서버의 예시에도 등장한다. 운영 상태 확인 질문을 보냈으며 답변 전에는 접속 가능이라고 단정하지 않는다.
8. 다섯 번째 역사 항목의 161 유래 연도는 한국어에 2023년, 영어에 2024년으로 다르게 기록되어 있다. 운영자가 확인하지 않은 역사적 사실을 임의로 수정하지 않는다.

## 이미지와 반응형 현황

실제 StimeMC 이미지 7개가 `public`에 PNG로 보존되어 있다. 원본 총 크기는 약 26.6 MB이며, Hero 원본은 약 6.8 MB다. 이는 실제 네트워크 전송량이 아니라 저장된 원본 크기다. Hero는 이미 `next/image`, `sizes`, `priority`를 사용한다.

현재 파일과 설명에는 이미지가 새 전쟁 서버에서 촬영됐다는 증거가 없다. 출처가 확인되지 않은 이미지를 전쟁 서버의 실제 플레이 화면으로 소개하면 안 된다. Survival에는 아직 실제 서버 이미지가 없다.

현재 화면은 검정 기반, 흰색 타이포, 큰 월드 이미지, 얇은 경계선과 각진 UI를 사용한다. Header는 1000px 이하에서 주요 링크를 감추고 전체 메뉴로 전환한다. 메뉴에는 스크롤 잠금, Escape 닫기, 포커스 순환·복귀가 있다.

모바일 Hero에는 `min-height: max(700px, 100svh)`가 있으며, 일부 본문 페이지의 Framer Motion 진입 효과는 개별 reduced-motion 처리가 없다. 태블릿은 주로 기존 CSS breakpoint에 의존한다.

브라우저에서 데스크톱·좁은 화면의 기존 Hero를 관찰했다. 이번 검사에서는 브라우저가 요청한 viewport 크기와 실제 DOM viewport가 달라, 지정된 기기별 화면 검증을 완료했다고 주장할 수 없다. 전체 요청 viewport, 회전, 터치·키보드, reduced-motion 검증은 리디자인 구현 후 수행해야 한다.

## 오래된 문서와 현재 구현의 차이

`DESIGN.md`와 `REDESIGN_NOTES.md`에는 제거된 가입 신청, 음성 채널, 예전 단일 서버 정체성이 남아 있다. 현재 기능의 기준은 실행 코드, 최근 커밋, 공개 화면이다. 리디자인 설계가 승인되면 문서도 현재 방향에 맞게 정리해야 한다.
