## 검증 결과

- 전체 자동 테스트 **94개 통과**, 린트 및 TypeScript 포함 프로덕션 빌드 통과.
- 10개 화면 크기 × 7개 장면: 360×640, 360×800, 430×932, 768×1024, 1366×768, 1440×900, 2560×1080, 844×390, 667×375, 740×360.
- 가로 넘침, 설명 하단 잘림, 카드/가입 버튼 실제 사각형 겹침 없음. 70장 캡처 중 데스크톱·모바일·짧은 세로·가로 핵심 장면을 직접 확인.
- 언어 변경, 메뉴 키보드 포커스, 가입 경로 및 뒤로가기, 네이티브 터치 스크롤 검사 통과.
- OS reduced-motion, WebGL 미지원/컨텍스트 손실, 자산 누락·손상, 로딩 취소, JavaScript 비활성 대체 화면 검사 통과.
- 테스트 로그/스크린샷: 로컬 `scratch/cinematic/` (버전 관리 제외).

## 성능 측정

마을은 **27,862 triangles**, 압축 기하 데이터 **64,782 bytes**, GPU 정점/인덱스 약 **3.45 MB**. 전환 지점 측정은 **9 draw calls / 41,350 triangles**. 검사한 장면은 모두 20 calls / 45k triangles / 2.4M framebuffer pixels 예산 이내입니다.

Intel UHD/Chrome에서 5.5초 스크롤 측정: 6배 CPU 제한 데스크톱과 4배 제한 모바일은 자동 LOW로 작동했습니다. 초기 전체 검사에서 브라우저 RAF p95는 각각 20.8ms/8.5ms, 50ms 이상 작업은 각각 1개(52ms)/0개였습니다. 이는 브라우저 RAF 지표이며 GPU 완료 시간이나 실제 디스플레이 FPS를 뜻하지 않습니다. 정지한 물리 세계 장면은 렌더를 중단하고, 기술 장면은 계속 움직입니다.

1.28Mbps, 150ms 지연, CPU 4배 제한: 첫 표시 1.60초, LCP 2.70초, 3D 준비 5.84초. JS 전송 약 425KB. SwiftShader 소프트웨어 WebGL도 동작했으며 해당 검사 RAF p95는 33.4ms였습니다.

실제 저가 휴대폰의 발열·배터리·GPU 프레임 완료 시간은 이 데스크톱 에뮬레이션으로 검증할 수 없습니다. 측정값은 이번 로컬 실행 결과이며 기기별 보장 수치가 아닙니다.
