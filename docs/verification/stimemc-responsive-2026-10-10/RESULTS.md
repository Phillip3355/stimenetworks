## 보정 내용

- 보조 글자와 이미지 설명을 최소 12px로 조정했습니다. 입력칸은 16px, 주요 모바일·터치 조작 영역은 최소 44px입니다.
- 280px 폴드 커버 화면의 헤더 간격과 제목 크기를 조정하고, 좁은 화면의 에디션·서버 카드를 한 열로 배치했습니다.
- 회색 배경 위 보조 글자의 대비를 높였습니다. Markdown 코드와 표는 키보드로 가로 스크롤할 수 있습니다.
- 규정·복구 번호와 뉴스 화살표의 고정 폭을 제거해 200% 글자 확대 시 잘리지 않도록 했습니다.
- 문의·관리 화면은 실제 사용 가능한 너비에 따라 접힙니다. 회원의 새 문의·로그아웃과 보고서 조작 버튼도 공통 스타일을 적용했습니다.
- drawer는 짧은 화면에서 내부 스크롤과 닫기 버튼을 유지합니다. 메뉴·disclosure·스크롤 진입 효과는 동작 줄이기 설정을 따릅니다.
- 대화 자동 스크롤은 메시지 영역 안에서만 동작합니다. 한 열의 대화를 처음 열면 고정 헤더 아래로 이동해 입력칸이 보이도록 했습니다. 기존 구현에서 입력칸 위치 검사가 실패하는 것을 재현한 뒤 보정 후 통과를 확인했습니다.
- 향후 공개되는 접속 정보의 복사·수동 복사 영역도 서버 패널 전체 폭을 사용합니다. 실제 서버의 미공개 접속 정보는 계속 비공개입니다.
